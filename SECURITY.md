# Security policy

## Supported versions

Only the latest release and `main` receive security fixes.

## Reporting a vulnerability

Report privately through the repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue for security problems.

Problems in Scramjet, the libcurl transport or wisp-js themselves belong with [Mercury Workshop](https://github.com/MercuryWorkshop); report them there.
